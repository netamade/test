# スプレッドシート変更通知（Google Apps Script）

Google スプレッドシートが編集されるたびに、**どのシートのどのセルが、何から何に変わったか** を
共有者（オーナー・編集者・閲覧者）にメールで通知します。

## 設置手順

1. 対象のスプレッドシートを開き、「拡張機能 > Apps Script」を開く
2. `Code.gs` の内容を貼り付けて保存
3. 上部の関数選択で `setup` を選び「実行」→ 権限を承認
4. 以上。以後は編集のたびにメールが届きます（停止は `teardown` を実行）

## メールの例

| セル | 変更前 | 変更後 |
|------|--------|--------|
| B3   | 未着手 | 完了   |
| D10  | (空)   | =SUM(D2:D9) |

- セル番地はクリックすると該当セルが開くリンクになっています
- 行/列の挿入・削除、シートの追加・削除も通知されます

## 設定（`CONFIG`）

| 項目 | 説明 |
|------|------|
| `DIGEST_MINUTES` | `0` で即時送信。`1/5/10/15/30` にすると、その間隔でまとめて 1 通送信 |
| `EXTRA_RECIPIENTS` / `EXCLUDE_RECIPIENTS` | 追加/除外したい宛先 |
| `INCLUDE_VIEWERS` | 閲覧者・コメント可ユーザーにも送るか |
| `EXCLUDE_EDITOR` | 編集した本人には送らない |
| `MAX_ROWS_IN_MAIL` | 1 通に載せる最大セル数 |

設定を変えたら `setup` を再実行してください。

## 仕組み

- 変更前の値は、非表示シート `__snap__<シートID>` に保存したスナップショットと比較して求めます。
  そのため貼り付けや範囲削除など、複数セルの一括変更でも変更前の値が分かります
  （標準の `e.oldValue` は単一セル編集時しか取れないため）。
- 非表示シート `__snap__*` / `__notify_queue__` は削除・編集しないでください。

## 注意点

- **送信数の上限**: 無料の Gmail アカウントは 1 日 100 宛先、Google Workspace は 1,500 宛先まで。
  共有者が多い・編集が頻繁な場合は `DIGEST_MINUTES` でまとめ送信にしてください。
- **編集者名**: Google のプライバシー制限で、別ドメインのユーザーなどは「不明なユーザー」と表示される場合があります。
- メールはスクリプトを `setup` した人のアカウントから送信されます。
- 数式の再計算による値の変化や、別のスクリプトによる変更は onEdit で検知されないため通知されません。
- スナップショット分だけセル数を消費します（スプレッドシート全体の上限は 1,000 万セル）。
